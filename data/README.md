# Dataset source

`Heart_disease_cleveland_new.csv` is a public, anonymized version of the Heart Disease Cleveland dataset.

- Original source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/45/heart+disease)
- CSV source: [Heart Disease Cleveland on Kaggle](https://www.kaggle.com/datasets/ritwikb3/heart-disease-cleveland)

The dataset contains 303 observations, 13 predictor variables and a binary target variable. Patient names and direct identifiers are not included.
